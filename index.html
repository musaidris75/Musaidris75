Welcome to StudyHub

A simple Flask web application where students can create an account. Your details are saved in a MySQL database and your password is hashed.

Create an Account

About this app

  • Backend: Python Flask
  • Frontend: HTML and Bootstrap 5
  • Database: MySQL (table tbl_user)
  • Security: passwords are hashed before saving

How to join

  1. Click Sign Up in the menu.
  2. Choose a username and a password.
  3. Confirm your password and submit the form.
